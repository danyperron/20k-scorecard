# 20K Scorecard

Feuille de pointage pour le jeu de dés 20 000 (iPhone / iPad).

Installation : ouvrir le lien GitHub Pages dans Safari → Partager → « Ajouter à l'écran d'accueil ».

Mise à jour : remplacer `index.html`, puis changer `VERSION` dans `index.html` et `CACHE` dans `sw.js` (même numéro).
